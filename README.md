# Online_BookStore_SQL_Project
## Executive Summary

This project analyzes an online bookstore's books,
customers, and order data using PostgreSQL to identify
sales trends, customer behavior, revenue drivers, and
inventory patterns.



### Key Performance Indicators

| KPI | Value |

| Total Books | 500 |
| Total Customers | 500 |
| Total Orders | 500 |
| Books Sold | 2697 |
| Total Revenue | $75628.66 |
| Average Order Value | $151.26 |
| Average Books per Order | 5.39 |



### Key Findings

• 'Romance' generated the highest revenue.
• 'Realigned multi-tasking installation' was the best-selling book.
• 'Kim Turner' was the highest-spending customer.
• '45.28%' of purchasing customers were repeat customers.
• 'Expanded local infrastructure(Mystery)' showed potential inventory risk.


### Business Recommendations

• Prioritize replenishment of high-demand, low-stock books.
• Focus promotional campaigns on high-performing genres.
• Develop retention campaigns for one-time customers.
• Review slow-moving inventory for pricing or promotional opportunities.
